# The scoreboard

HPR Sim against OpenRocket 24.12 and RocketPy 1.13.0, axis by axis, by the project's standard: never worse than the best comparable tool on any axis it measures ([ADR-209](https://github.com/nrdptel/fusionspace-eridanus/blob/main/docs/decisions/0209-the-2026-10-08-best-on-the-market-measured.md), the decision record that set it). Generated by `cargo xtask scoreboard` from the committed reports: each number is read from the report and key the sources below name, rounded as printed; a cell no report measures yet says so and links the milestone that will.

**Where it stands.** 14 of the 51 cells below are measured: HPR Sim's 7 of 15, OpenRocket 24.12's 6 of 18, RocketPy 1.13.0's 1 of 18. 8 say another tool can't do the row's task that way, and 2 that HPR Sim can't yet. Where HPR Sim and another tool can be set side by side: `accuracy.collection`, HPR Sim 12.95% and OpenRocket 24.12 12.02%: OpenRocket 24.12 ahead; `bias.collection`, HPR Sim +8.73% and OpenRocket 24.12 +7.79%: OpenRocket 24.12 ahead; `features.count`, HPR Sim 12 and OpenRocket 24.12 7: HPR Sim ahead; `features.count`, HPR Sim 12 and RocketPy 1.13.0 8: HPR Sim ahead; `steps.command-line`, HPR Sim 2 and OpenRocket 24.12 can't: HPR Sim has a way, OpenRocket 24.12 none; `steps.command-line`, HPR Sim 2 and RocketPy 1.13.0 can't: HPR Sim has a way, RocketPy 1.13.0 none; `steps.script`, HPR Sim 10 and OpenRocket 24.12 can't: HPR Sim has a way, OpenRocket 24.12 none; `steps.script`, HPR Sim 10 and RocketPy 1.13.0 can't: HPR Sim has a way, RocketPy 1.13.0 none; `steps.window-clicks`, HPR Sim can't yet: no window and OpenRocket 24.12 7 clicks to fly; `steps.window-entries`, HPR Sim can't yet: no window and OpenRocket 24.12 0 entries to fly.

> **How far to trust it.** A cell is exactly as good as the report it comes from. Errors are each simulator's apogee less the logged one, over the logged one; the private collection's are aggregates of flights whose designs and logs are not public. A check fails when one of HPR Sim's numbers gets worse than this page, or counts fewer flights or designs, or a measured cell is no longer measured, unless an accepted decision record names that cell and the release the change ships in ([ADR-240](https://github.com/nrdptel/fusionspace-eridanus/blob/main/docs/decisions/0240-the-scoreboard.md), how the check works). The other tools' numbers are shown, not held, and so is speed.

## Reading it

- **A cell's id** is its row's and its tool's, such as `accuracy.public.hpr`: the name a decision record uses to accept a worse number.
- **Not measured** means no committed report measures the cell yet; its link names the milestone that will. Those milestones, and the cells each fills:
  - [M2.3c7, published flights past Mach 1](https://hpr.fusionspace.co/decisions-and-roadmap.html#m2-3c7): `accuracy.supersonic.hpr`.
  - [M2.6, an open benchmark](https://hpr.fusionspace.co/decisions-and-roadmap.html#m2-6): `accuracy.public.openrocket`, `bias.public.openrocket`.
  - [M2.7, held-out flights](https://hpr.fusionspace.co/decisions-and-roadmap.html#m2-7): `accuracy.held-out.hpr`, `accuracy.held-out.openrocket`, `bias.held-out.hpr`, `bias.held-out.openrocket`.
  - [M2.8, honest uncertainty](https://hpr.fusionspace.co/decisions-and-roadmap.html#m2-8): `uncertainty.range-50.hpr`, `uncertainty.range-90.hpr`.
  - [M2.9, the other tools' cells](https://hpr.fusionspace.co/decisions-and-roadmap.html#m2-9): `accuracy.public.rocketpy`, `accuracy.collection.rocketpy`, `accuracy.held-out.rocketpy`, `accuracy.supersonic.openrocket`, `accuracy.supersonic.rocketpy`, `bias.public.rocketpy`, `bias.collection.rocketpy`, `bias.held-out.rocketpy`, `uncertainty.range-50.openrocket`, `uncertainty.range-50.rocketpy`, `uncertainty.range-90.openrocket`, `uncertainty.range-90.rocketpy`, `speed.flight.hpr`, `speed.flight.openrocket`, `speed.flight.rocketpy`, `interop.changed.rocketpy`, `interop.failed.rocketpy`, `interop.largest.rocketpy`.
  - [M9.1, the desktop app](https://hpr.fusionspace.co/decisions-and-roadmap.html#m9-1): `steps.window-clicks.hpr`, `steps.window-entries.hpr`.
- **can't** means the tool has no way to do the row's task that way, by the source *Steps, one by one* names; **can't yet** is HPR Sim's, with the milestone that brings it.
- **n/a:** a round-trip row measures HPR Sim reading and writing another tool's file, so HPR Sim has no cell of its own there.

## Steps to a first answer

How many steps it takes to open a design, fly it once and see its apogee, and get its landing spread: where it may land, from many flights with their inputs scattered (a [Monte Carlo](https://hpr.fusionspace.co/glossary.html#monte-carlo) run). It starts fresh, with the design's `.ork` file on disk. Each command, script line, click and typed entry is a step, each kind counted apart; a step that serves two tasks counts once. HPR Sim's are counted from files a test runs; the other tools' from their documentation, listed one by one under *Steps, one by one* below. A tool that can't do a task a way says so, with the steps to the last task it reaches.

| measure | better | HPR Sim | OpenRocket 24.12 | RocketPy 1.13.0 |
|---|---|---:|---:|---:|
| Commands typed at a command line to open a design, fly it and get its landing spread (`steps.command-line`) | lower | 2 | can't: no command flies a design: its command-line arguments set options for the window | can't: no command flies a design: RocketPy is a Python library |

## Steps, one by one

Each step the steps rows count, from a fresh start: the tool installed and open, or a terminal or a Python session, and the design's `.ork` file on disk with its motor chosen (and, for OpenRocket, a simulation saved in it). Installing isn't counted. A command is one command line, a script line one statement, a click one press of the mouse (a double click is one) and an entry one value typed ([ADR-241](https://github.com/nrdptel/fusionspace-eridanus/blob/main/docs/decisions/0241-steps-to-a-first-answer.md), the rules). These are counts of documented steps, not timings or a test with flyers.

### HPR Sim

Counted on 2026-10-11 from files a test runs on every change ([`crates/hpr-py/tests/test_first_answer.py`](https://github.com/nrdptel/fusionspace-eridanus/blob/main/crates/hpr-py/tests/test_first_answer.py)), so each step works.

- **Command line** ([`validation/steps/hpr-command-line.txt`](https://github.com/nrdptel/fusionspace-eridanus/blob/main/validation/steps/hpr-command-line.txt)):
  - *open, fly:*
    1. command: `hpr sim validation/fixtures/ork/guides/level-1.ork`
  - *spread:*
    2. command: `hpr mc validation/fixtures/ork/guides/level-1.ork --wind 4 --wind-from 270 --wind-sd 0.25 --wind-from-sd 15`
- **Script** ([`validation/steps/hpr-python.py`](https://github.com/nrdptel/fusionspace-eridanus/blob/main/validation/steps/hpr-python.py)):
  - *open:*
    1. line: `from fusionspace import hpr`
    2. line: `rocket = hpr.Rocket.from_file("validation/fixtures/ork/guides/level-1.ork", recovery=True)`
  - *fly:*
    3. line: `calm = hpr.Environment(0.0, 0.0, 0.0)`
    4. line: `flight = hpr.Flight(rocket, calm, 1.5)`
    5. line: `print(f"apogee {flight.apogee_m:.1f} m")`
  - *spread:*
    6. line: `import numpy`
    7. line: `windy = hpr.Environment(0.0, 0.0, 0.0, wind_speed_m_s=4.0, wind_from_deg=270.0)`
    8. line: `run = hpr.MonteCarlo(rocket, windy, 1.5, wind_sd_fraction=0.25, wind_from_sd_deg=15.0)`
    9. line: `axes = numpy.sqrt(numpy.linalg.eigvalsh(numpy.cov(run["landing_east_m"], run["landing_north_m"])))`
    10. line: `print(f"landing ellipse, one standard deviation: {axes[1]:.1f} m by {axes[0]:.1f} m")`
- **Window:** can't: no window ([M9.1, the desktop app](https://hpr.fusionspace.co/decisions-and-roadmap.html#m9-1)).

### OpenRocket

Counted on 2026-10-11 from the documentation of OpenRocket 24.12, released 2025-07-27.

Its guide is built from its development branch and titled with an older release, and its screenshots predate 24.12's reworked simulation table, so a click may differ in 24.12. The count assumes the file dialog already shows the design's folder and a simulation saved in the file; a preference that runs a simulation when its tab opens, whose default the guide doesn't give, would save 2 clicks.

- **Command line:** can't: no command flies a design: its command-line arguments set options for the window ([OpenRocket's guide: Command Line Arguments](https://openrocket.readthedocs.io/en/latest/dev_guide/command_line_arguments.html)).
- **Script:** can't: no documented script flies a design: the guide to its Java core loads one but stops at a commented-out `simulation.simulate()` and shows no apogee; the separate orhelper wrapper isn't in OpenRocket's documentation ([OpenRocket's guide: Using OpenRocket Core in External Applications](https://openrocket.readthedocs.io/en/latest/dev_guide/using_openrocket_core.html)).
- **Window:**
  - *open:*
    1. click: the File menu ([OpenRocket's guide: Getting Started (the File menu)](https://openrocket.readthedocs.io/en/latest/setup/getting_started.html)).
    2. click: Open… ([OpenRocket's guide: Getting Started (the File menu)](https://openrocket.readthedocs.io/en/latest/setup/getting_started.html)).
    3. click: the design's file, in a file dialog already showing its folder ([OpenRocket's guide: Getting Started (the File menu)](https://openrocket.readthedocs.io/en/latest/setup/getting_started.html)).
    4. click: the dialog's Open button ([OpenRocket's guide: Getting Started (the File menu)](https://openrocket.readthedocs.io/en/latest/setup/getting_started.html)).
  - *fly:*
    5. click: the Flight Simulations tab ([OpenRocket's guide: Getting Started (the File menu)](https://openrocket.readthedocs.io/en/latest/setup/getting_started.html)).
    6. click: the design's simulation, saved in its file ([OpenRocket's guide: Basic Flight Simulation](https://openrocket.readthedocs.io/en/latest/user_guide/basic_flight_simulation.html)).
    7. click: Run simulations; the apogee shows in the simulation's row ([OpenRocket's guide: Basic Flight Simulation](https://openrocket.readthedocs.io/en/latest/user_guide/basic_flight_simulation.html)).
  - *spread:* can't: no Monte Carlo in 24.12, the newest release: its release notes add none, and its development branch's landing-dispersion analysis is in no release ([OpenRocket 24.12's release notes](https://github.com/openrocket/openrocket/releases/tag/release-24.12)).

### RocketPy

Counted on 2026-10-11 from the documentation of RocketPy 1.13.0, released 2026-07-22.

RocketPy flies a rocket typed in as Python and scatters it in a Monte Carlo run; what it can't do is start from the design's `.ork` file, which is the task here.

- **Command line:** can't: no command flies a design: RocketPy is a Python library ([RocketPy's documentation](https://docs.rocketpy.org/en/latest/)).
- **Script:**
  - *open, fly, spread:* can't: no `.ork` reader: its documentation names no way to load one, and a design is typed in as Python, its drag curves, masses and inertias included ([RocketPy's guide: First Simulation](https://docs.rocketpy.org/en/latest/user/first_simulation.html)).
- **Window:** can't: no window: RocketPy is a Python library ([RocketPy's documentation](https://docs.rocketpy.org/en/latest/)).
