# How the pages read

This page is the voice check's report: how each page reads against the limits in
[the writing guide's voice section](writing.md#voice). The site's build writes it from the pages
each time it runs, so this file holds only its place. Read it on the site, or print it from a copy
of the repository with `cargo xtask voice`.

> **How far to trust it.** The counts find the patterns the writing guide lists in each page's words. They miss other awkward sentences, so a page within every limit can still read badly. The build writes them from the pages each time, so they match the pages the site shows.
