# How the pages read

How each page reads against the writing guide's voice limits, written from the pages by the site's build each time it runs.

> **How far to trust it.** The counts find the patterns the writing guide lists in each page's words. They miss other awkward sentences, so a page within every limit can still read badly. The build writes them from the pages each time, so they match the pages the site shows.

This file holds only the page's place. Read the report on the site, or print it from a copy of
the repository with `cargo xtask voice`; [the writing guide's voice section](writing.md#voice)
sets the limits.
